# artifacts2 — archived results

Every number quoted in the dissertation was produced by a script in this repository and
recorded here when that script finished. These files are **outputs, not inputs**: receipts
of experiments that already ran, kept so a reader can check a claim without a GPU.

Filenames map one-to-one onto scripts: `fuse_final.py` writes `fuse_final_v1.json`,
`coat_pattern_diag.py` writes `coat_pattern_diag_v1.json`. To verify a number, run the script
that owns the file and compare.

## What a file looks like

Each JSON is a flat dictionary whose keys name experiment conditions in plain words and whose
values are metric blocks:

```json
"k2-students mean (s7,s8,s9)": {
  "rank-1": 0.8834, "rank-5": 0.9571, "rank-10": 0.9693, "mAP": 0.5359,
  "n_query_scored": 163, "n_gallery": 834
}
```

The query and gallery counts are embedded in every block, so each number carries the evidence
of which protocol produced it. Recurring keys: `P1` (leave-out camera 66.130, 163 queries
against 834 gallery tracklets), `P2` (full transductive), `query_66.x` (one per camera),
`dorsal_mean_r1` (mean over the six overhead cameras), and `plain` versus `st` for a metric
scored with and without the spatio-temporal prior. Diagnostic files additionally record their
own provenance: the script name, the checkpoint or embedding file, and the seed.

|---|---|---|

| Spatio-temporal | 5 | Camera-topology prior, with and without ST masking |

| Early baselines | 2 | Superseded warm-up runs |

## Three files that are inputs, not outputs

`split_leave_out_66.130.json`, `split_random_open_set.json` and `distill_labels_v1.json` are
frozen contracts read back by later training and evaluation. Regenerating them would shift
every downstream number, which is why they are committed rather than recomputed.

## The CSV files

| File | Contents |
|---|---|
| `topology_gt.csv` | The 21 camera-pair overlap weights measured from the recording; source of the topology figure |
| `tier3_clusters.csv` | Pseudo-identity assigned to each of the 1,079 tracklets (self-generated labels, not ground truth) |
| `labels_noise_sym20.csv`, `labels_noise_sym50.csv` | Label sets with 20% and 50% symmetric noise injected on purpose, for the noise-tolerance experiments |
| `labels_scrambled_permute.csv` | Fully scrambled labels: the control that shows the accuracy is not an artefact of leakage |

`manifest.csv`, `pairs_tier1.csv` and `pairs_tier2.csv` are regenerated by
`repro/build_phase1.py` and are excluded from the repository for size (61 MB combined).
