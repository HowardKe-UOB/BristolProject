# inference-stack

## Pipeline order (champion label-free inference stack)  [eval_sweep.py:29-40]
champ_dist(): for EACH model checkpoint m: (1) embed all eval tracklets with flip-TTA -> 768-d unit vectors; (2) camera-center the concatenated [Q;G] features -> (Qcc,Gcc); (3) PCA-whiten raw (NOT camera-centered) features, fit on gallery Gf only, n_dim=256 -> (Qw,Gw); (4) compute three distance matrices: d1=cosine(Qcc,Gcc), d2=cosine(Qw,Gw), d3=CA-Jaccard(Qcc,Gcc,k1=30,k2=6,camera_aware); (5) fuse by reciprocal-rank fusion with k=20 -> per-model distance D_m; (6) final distance = (1/M) * sum_m D_m (arithmetic mean over models). Steps 7 (cluster bonus) and 8 (ST mask) are optional add-ons applied to this fused distance in cluster_rerank_guard.py and via build_st_mask respectively; eval_sweep.py itself applies NEITHER.

## (1) Read-out feature: pre-projection 768-d attention-pooled backbone feature  [eval_cap_ensemble.py:36-49; train_finetune_iics.py:42-44; cowreid/iics.py:54-71; cowreid/encoder.py:15-35,55-70; vitb_unsup.py:36]
embed_tta extracts e = F.normalize(model.head.pool(model._frames(x)), dim=1). model._frames runs the DINOv2 ViT-B/14 backbone (timm 'vit_base_patch14_dinov2.lvd142m', num_classes=0, embed_dim=768) on each of the T frames independently and reshapes to (B,T,768). model.head.pool is TemporalPool(mode='attn'): w_t = softmax_t(Linear_{768->1}(f_t)); pooled = sum_t w_t * f_t. This is the PRE-projection feature: the trained 256-d projection head (head.embed = Linear(768->256) + AIBN1d + ReLU, followed by L2 in head.backbone()) is BYPASSED at inference. Computed under torch.autocast('cuda', float16), batch size bs=8, model.eval().

## (1) Flip-TTA averaging formula  [eval_cap_ensemble.py:37-49]
For flip in (False, True): x_flip = torch.flip(x, dims=[-1]) (horizontal flip along width). Each pass yields an L2-normalized vector v (normalized once on GPU via F.normalize, re-normalized in float32 numpy). Accumulation: out[t] = v_orig/||v_orig|| + v_flip/||v_flip||; final embedding e_t = out[t] / (||out[t]|| + 1e-12). I.e., the TTA feature is the L2-normalized SUM of the two unit vectors (equivalently normalized mean), NOT an average of raw un-normalized features.

## Eval frame sampling: T=8 uniform, two-stage  [vitb_unsup.py:41,69-96; train_phase2_run.py:52-55; eval_sweep.py:47,63; eval_cap_ensemble.py:77,87]
Stage A (loader construction): sample_frames(tracklet, k=8) pre-selects up to 8 crop paths with idx = linspace(0, n_paths-1, min(8, n_paths)).astype(int) over the tracklet's FULL crop list. Stage B (eval batch, train=False): idx = linspace(0, n-1, min(T, n)).astype(int) over the Stage-A list, padded by repeating the LAST index if n < T (so short tracklets repeat their last frame). With frames=T=8 both stages, Stage B is identity. Images come from a uint8 cache at 518x518 (IMG=518), scaled /255 and normalized with ImageNet mean (0.485,0.456,0.406) / std (0.229,0.224,0.225) on GPU. eval_sweep --frames default 8; eval_cap_ensemble hardcodes 8.

## (2) camera_center exact operation  [new_levers.py:79-87,65-76; eval_sweep.py:35-36]
camera_center(items, X, strength=1.0): X <- X/||X|| (row L2); group indices by item.camera; for each camera c: X_c <- X_c - strength * mean(X_c) (mean over that camera's rows of the NORMALIZED features); output <- row-L2-renormalized. NO variance/std scaling (that is the separate non-champion per_camera_whiten lever which does (X_c - mu_c)/sd_c^strength). Champion uses strength=1.0 (default). It is applied to the CONCATENATED query+gallery matrix (items = list(q)+list(g), X = concat[Qf,Gf]), so the held-out camera's mean is estimated from the queries themselves — transductive but label-free.

## (3) pca_whiten exact operation  [new_levers.py:53-62; eval_sweep.py:37; eval_cap_ensemble.py:98]
pca_whiten(fit_X=Gf, apply_Xs=[Qf,Gf], n_dim=256, eps=1e-3, shrink=0.0): mu = mean(Gf); Xc = Gf - mu; SVD Xc = U S V^T (full_matrices=False); keep first 256 rows of V^T and first 256 singular values; per-component std d_j = S_j / sqrt(N_gallery) (population scaling, N not N-1); projection W = V_{:256}^T / (d*(1-shrink) + mean(d)*shrink + eps) with shrink=0 so divisor is simply d_j + 1e-3; output for any X: l2((X - mu) @ W), i.e. whitened coordinates re-L2-normalized. Fit on gallery ONLY (label-free), applied to both query and gallery. CRITICAL: in champ_dist it is fit/applied on the RAW TTA features Qf/Gf, not the camera-centered ones.

## (4) dist_rerank / CA-Jaccard distance, champion k1=30 k2=6  [new_levers.py:110-113; cowreid/cajaccard.py:20-65; eval_sweep.py:39; eval_cap_ensemble.py:100]
dist_rerank(Q,G,cams,k1,k2): feats = concat[Q;G] (camera-centered features in champion), D = ca_jaccard_distance(feats, cams, k1, k2, camera_aware=True), return D[:Nq, Nq:]. Inside ca_jaccard_distance: rows L2-normalized; original_dist = clip(1 - F F^T, 0, inf); initial_rank = per-row argsort. For each i: k-reciprocal set R(i,k1) = {j in top-(k1+1) of i : i in top-(k1+1) of j}; local expansion: for each j in R(i,k1), candidates C = R(j, round(k1/2)); C added if |C ∩ R(i,k1)| > (2/3)|C|. CAMERA-AWARE step: unconditionally add the max(1, k1//2) nearest samples (by original_dist) whose camera differs from camera(i) — with k1=30 that is the 15 nearest inter-camera samples. Membership vector: V[i, kr_exp] = exp(-original_dist[i,kr_exp]) / sum(exp(-original_dist[i,kr_exp])). Local query expansion (k2=6): V[i] <- mean of V over i's top-k2 initial neighbours (includes self since rank 0 is self). Jaccard: J[i,j] = 1 - sum_d min(V[i,d],V[j,d]) / (sum_d max(V[i,d],V[j,d]) + 1e-12); symmetrized J <- 0.5(J + J^T); lambda_value=0.0 so NO blending with original distance (pure Jaccard, unlike Zhong et al. 2017 lambda=0.3); diagonal set to 0. Champion passes k1=30, k2=6 explicitly (dist_rerank's own defaults are k1=20, k2=6).

## (5) RRF fusion of three distance views, k=20  [new_levers.py:116-130; eval_sweep.py:38-39; eval_cap_ensemble.py:99-100]
The three fused views (per model, single embedding space): (i) cosine distance on camera-centered features 1 - Qcc Gcc^T; (ii) cosine distance on PCA-whitened-256 features 1 - Qw Gw^T; (iii) CA-Jaccard(k1=30,k2=6) on camera-centered features. rrf(dists, k): for each view v, rank_v(i,j) = 0-based position of gallery j in ascending sort of row i (stable argsort; 0 = nearest); fused(i,j) = - sum_v 1/(k + rank_v(i,j)). Champion calls pass k=20 (the rrf function DEFAULT is k=60 — the classical RRF constant — but it is overridden). Because ranks are 0-based, the nearest item contributes 1/20 per view. Output is a negative score used directly as a distance.

## (6) Cross-model fusion = arithmetic mean of per-model champion RRF distances  [eval_sweep.py:29-40; eval_cap_ensemble.py:94-120]
champ_dist(q,g,embs_list,ids,cams): loops over each model's embedding matrix, computes the full per-model champion pipeline ending in the RRF-fused distance D_m, then returns np.mean(dists, axis=0). Justified in eval_cap_ensemble comment: 'they are RRF scores, same scale'. eval_cap_ensemble also evaluates alternatives — (a) per-seed feature CONCAT then champion recipe, (b) RRF over the per-seed champion distances (k=20), (c) mean of per-seed champion distances — and an oracle-only 'drop worst seed' reference explicitly labelled oracle (no GT used for selection in the deployed method). eval_sweep's champ_dist implements variant (c).

## (7) Cluster-consistency rerank: DBSCAN space, constraints, bonus  [cluster_rerank_guard.py:22,36,42-66; cowreid/cajaccard.py:68-90; cowreid/cluster.py:21-43]
Feature space: Xf = l2( mean_m( l2(M_m) ) ) — mean over the (4-model) per-row-L2-normalized embedding matrices, re-L2-normalized (NOT the RRF distance space). One GLOBAL clustering over ALL tracklet ids (all cameras, reused unchanged for P1/per-camera/P2): lab = dbscan_cluster(sids, Xf, cams, eps=0.5, cannot_link=cl) with dbscan_cluster defaults min_samples=2, k1=20, k2=6, camera_aware=True. It computes D = ca_jaccard_distance(Xf, cams, 20, 6, camera_aware=True); then for every cannot-link pair (a,b): D[a,b]=D[b,a]=1.0 (max Jaccard distance) so the pair is never DIRECTLY density-linked (transitive merges through other points remain possible); DBSCAN(eps=0.5, min_samples=2, metric='precomputed'); DBSCAN noise points (label -1) are converted to their own singleton clusters. Cannot-link set: build_cannot_link(tracklets, topo, 0.02) = all tracklet pairs with overlapping time intervals that are EITHER same-camera OR in a non-overlapping camera pair (topology weight < 0.02). Rerank: boosted(i,j) = base_champ_dist(i,j) - 0.05 * [cluster(i)==cluster(j)], i.e. BONUS=0.05 SUBTRACTED from the RRF-scale fused distance for same-cluster query-gallery pairs; EPS=0.5, BONUS=0.05 defined as constants.

## (8) Spatio-temporal impossibility mask rule  [cowreid/st_inference.py:28-56,96-111; new_levers.py:155; eval_cap_ensemble.py:74; cowreid/topology.py:38-94]
build_st_mask(query, gallery, index, topo, overlap_thr=0.02, margin=0): mask[i,j] = True iff (a) camera(q_i) != camera(g_j) AND the pair's topology weight < overlap_thr=0.02 (fields of view do NOT overlap; same-camera pairs are never masked because the non_ov dict only contains a!=b and .get defaults to False), AND (b) the tracklets' time intervals intersect: min(qEnd_i, gEnd_j) - max(qStart_i, gStart_j) >= margin, with margin=0 in all call sites so even a zero-length touch (end==start) is masked. Masked entries are set to distance INF=1e6 AFTER the full distance pipeline including re-ranking ('the constraint is absolute so it overrides any similarity evidence'). Uses NO identity labels — only timestamps, camera ids, and the camera-overlap topology; the scripts here build the topology via CameraTopology.from_gt (oracle: fraction of co-occurring cross-camera crop pairs sharing an id), but a label-free estimator CameraTopology.estimate exists (mutual-NN/dustbin-OT match rate at co-occurring instants).

## Scoring protocol behind all numbers  [cowreid/eval.py:83-103; eval_sweep.py:26,94-135]
_score implements Market-1501-style tracklet-to-tracklet CMC/mAP from a precomputed (Nq,Ng) distance matrix: per query, stable ascending argsort; junk rule drops gallery items with SAME identity AND SAME camera as the query (forces cross-camera matches; also removes self in transductive P2); queries with no remaining true match are skipped entirely (not counted as failures); CMC@r = fraction of scored queries with a match in top r; AP = mean over match positions of cumsum(matches)/position. Protocols: P1 = leave-out camera '66.130' (queries = 66.130 tracklets whose id appears in the other-camera gallery); per-camera sweep = repeat with each camera as query side, 'dorsal mean r1' averages the non-66.130 cameras; P2 full transductive = query=gallery=all tracklets whose identity appears in >=2 cameras.

## Eval universe and tracklet construction  [eval_sweep.py:52-63,89-90; eval_cap_ensemble.py:62-92; new_levers.py:144-146]
Manifest from '2025Sep18.listing.txt'; tracklets built with build_tracklets(manifest, max_gap_s=2) (frames of same cow in same camera split when gap > 2 s). eval_sweep embeds ids = all tracklets EXCEPT hold-out-camera (66.130) tracklets whose gt_label is absent from the other-camera gallery. eval_cap_ensemble embeds only the P1 query+gallery tracklets. Per-model embeddings saved to npz ('_sweep_{tag}_emb.npz' / '_vitb_cap_ens5_emb_v1.npz') so all later fusion is CPU-only.

## new_levers.py role: the lever-ablation script that selected the champion  [new_levers.py:90-100,143-221]
new_levers.py operates on SAVED frozen embeddings ('_vitb_unsup_emb_v1.npz', keys feat768 = 768-d pooled backbone feature and emb256 = 256-d projection) and ablates label-free levers on P1: PCA-whitening (nd in {128,256,512}), per-camera whitening (z-score variant), DBA (gallery vector += kNN-weighted neighbours, k=6, alpha=3.0, weights w = clip(cos,0)^3 — NOT in the champion), a k1/k2 sweep over k1 in {8,12,20,30} x k2 in {2,3,6} selecting best by rank-1, RRF variants, and emb256+feat768 distance averaging (0.5*d_cos768 + 0.5*d_cos256 — not in champion). Its baseline 'CC+RR' uses the older defaults k1=20, k2=6 and rrf default k=60; the champion recipe (RRF(CC, PCAW256, CC-RR k1=30 k2=6), rrf k=20) is what eval_sweep/eval_cap_ensemble encode.

## GOTCHAS
- The inference feature is NOT the trained 256-d projection embedding: embed_tta reads model.head.pool(model._frames(x)) — the 768-d POOLED backbone feature BEFORE the Linear(768->256)+AIBN+ReLU projection (eval_cap_ensemble.py:45). Do not describe it as 'the model embedding'.
- Temporal pooling is a LEARNED single-query attention pool (w_t = softmax(Linear(768->1)(f_t)), pooled = sum_t w_t f_t; TemporalPool mode 'attn', cowreid/encoder.py:55-70), not simple mean pooling over the 8 frames.
- Flip-TTA is the L2-normalized SUM of the two per-pass unit vectors (equivalently the normalized mean of normalized embeddings), not an average of raw features (eval_cap_ensemble.py:47-49).
- RRF uses k=20 in the champion (explicit argument), not the literature-standard k=60 which happens to be the rrf() function default (new_levers.py:125 vs eval_sweep.py:39). Ranks are 0-based, so the top match contributes 1/(20+0).
- CA-Jaccard here is PURE Jaccard: lambda_value=0.0, so unlike Zhong et al. 2017 (final = 0.3*original + 0.7*Jaccard) there is no blending with the original cosine distance (cowreid/cajaccard.py:28,62-63). The matrix is also explicitly symmetrized 0.5*(J+J^T).
- Champion re-rank params are k1=30, k2=6 — but dist_rerank's own signature defaults to k1=20 and new_levers.py's 'CC+RR' baseline rows used k1=20/k=60 RRF; citing the defaults instead of the champion values is an easy error.
- camera_center subtracts the per-camera mean and RE-L2-NORMALIZES, with NO variance scaling; per-camera whitening (mean AND std) is a separate lever that was tested and is NOT in the champion (new_levers.py:65-87). It is transductive: computed jointly on query+gallery so the query camera's own mean comes from the queries.
- PCA-whitening is fit on the RAW gallery TTA features Gf (label-free, gallery-only), NOT on the camera-centered features, and its whitened output feeds a SEPARATE distance view — the CC view and the whitened view are parallel branches fused by RRF, not sequential (eval_sweep.py:35-39). Whitening scale is d_j = S_j/sqrt(N) (population, not N-1) with +1e-3 floor, then re-L2-normalization.
- Cross-model fusion averages the per-model champion RRF DISTANCE MATRICES (np.mean over models), not the features; feature-concat fusion exists only as ablation (a) in eval_cap_ensemble.
- The cluster-consistency DBSCAN runs in a DIFFERENT space from the retrieval distance: the L2-normalized mean of per-model L2-normalized embeddings, with CA-Jaccard at the DEFAULT k1=20/k2=6 (not champion 30/6), eps=0.5, min_samples=2. It is run ONCE globally over all tracklets and reused for every protocol; DBSCAN noise points become singleton clusters.
- Cannot-link constraints only prevent DIRECT density links (pairwise distance forced to 1.0 before DBSCAN); two cannot-link tracklets can still end up in one cluster through transitive density chains (cowreid/cajaccard.py:80-82). Cannot-link pairs = time-overlapping AND (same camera OR non-overlapping camera pair) (cowreid/cluster.py:21-43).
- The cluster 'bonus' is a constant 0.05 SUBTRACTED from the fused RRF-scale distance for same-cluster query-gallery pairs (boosted = base - 0.05*same); it is a soft prior, not a hard constraint.
- eval_sweep.py (the script producing the champion P1/per-camera/P2 numbers) applies NO ST mask; the '+ST' numbers exist only in new_levers.py and eval_cap_ensemble.py side columns. Do not claim the headline champion numbers include ST masking.
- The ST mask uses margin=0, which masks pairs whose intervals merely TOUCH (inter >= 0 includes zero-length intersection); same-camera pairs are never ST-masked (the non-overlap dict covers only distinct camera pairs). These scripts build the topology with CameraTopology.from_gt (oracle co-occurrence weights) — the label-free CameraTopology.estimate exists but is not what runs here.
- eval_cap_ensemble.py's docstring says '3-seed' but the code defines and runs FIVE seeds s0..s4 (SEEDS dict, line 30-31), and the printed section header still says '3-seed ensembles'. The 'drop worst seed' fusion is explicitly labelled oracle-only and uses GT — it is not part of the label-free method.
- Evaluation skips queries with no cross-camera true match entirely (they contribute to neither CMC nor mAP), and the junk rule removes same-id-same-camera gallery entries — in the transductive P2 protocol (query set == gallery set) this is what removes self-matches; mAP here averages only over scored queries.
- Frame sampling is double-staged: sample_frames pre-selects <=8 uniformly spaced crops per tracklet at loader construction, then eval-time linspace over that list (identity when both are 8); tracklets with <8 crops are padded by repeating the LAST frame, not by cycling.
